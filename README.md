# 딩동

선생님 바탕화면 앱 — 시간표·급식·일정·할 일·선생님 호출을 한 화면에서 봐요. (Windows 10/11)

## 설치

1. 오른쪽 **Releases**에서 가장 위에 있는 `Dingdong-Setup-버전.exe` 를 받아 실행해요. 관리자 권한은 필요 없어요.
2. 처음 실행하면 **"Windows의 PC 보호"** 화면이 뜰 수 있어요. 코드 서명이 없어서 나오는 안내예요. **추가 정보 → 실행** 을 누르면 돼요.
3. 설정에서 **학교**와 **날씨 지역**을 고르면 급식·학사일정·날씨가 채워져요.

## 업데이트

새 버전이 나오면 앱이 알아서 받아 두고, 화면 위쪽에 **"지금 다시 시작"** 안내를 띄워요. 눌러야 설치돼요.

## 내 데이터

- 시간표·할 일·일정·설정은 **각자의 컴퓨터에 저장**돼요. 재부팅하면 초기화되는 학교 PC라면 설정에서 저장 폴더를 D: 드라이브나 USB로 바꿔 두세요.
- 설정의 **백업 파일로 내보내기 / 가져오기**로 옮길 수 있어요. 노션·Gemini 키와 호출 로그인은 보안상 백업에 들어가지 않아요.
- 노션, Gemini(사진으로 일정 넣기), 컴시간, 선생님 호출은 **선생님이 직접 연결했을 때만** 해당 서비스와 통신해요.

## 쓰는 외부 서비스

나이스 교육정보 개방 포털(급식·학사일정) · Open-Meteo(날씨) · 노션(선택) · Google Gemini(선택) · 컴시간(시간표 가져오기, 비공식) · 선생님 호출 서버(선택)
